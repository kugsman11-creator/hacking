🧠 Step-by-Step Guide

1

Read the problem.
Don't immediately guess the answer. Identify what the code is checking.

2

Understand the input.
Ask: what data enters the program? Password? Username? Number? Text?

3

Follow the logic.
Read conditions from top to bottom and see what changes.

4

Test safely.
Run the code against harmless examples and observe the output.

5

Think like a defender.
After finding the weakness, ask how a programmer could prevent it.
